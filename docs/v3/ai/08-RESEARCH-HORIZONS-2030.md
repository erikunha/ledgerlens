# Open-Ended Research Horizons (2027-2030+)

No terminal 'final release'. The program supports speculative research tracks with explicit entry gates and source evidence. Promises of full autonomy or demonstrated ROI require actual tests, not aspirational features.

| Research track | Candidate technologies | LedgerLens demonstrator | Go/no-go evidence |
|---|---|---|---|
| Neuro-symbolic reasoning | program synthesis, formal constraint solvers | executable payment policy with generated explanation | zero invariant violations; complexity benchmark |
| Causal reasoning | SCMs, interventions, counterfactual inference | distinguish refund policy cause vs FX correlation | explicit assumptions, causal identifiability review |
| Risk-sensitive planning | Bayesian decisions, expected utility | abstention under loss asymmetry | calibrated event probabilities |
| Agent hierarchy | supervisors, delegations, planner-executor | specialist chains with typed tools | paired quality/cost improvement |
| Adaptive model routing | bandits, learned policy | route transaction types to provider/model | out-of-sample policy regret and safety |
| Learning to retrieve | trainable reranker, contextual indexing | policy passage ranking | relevance + outcome evals |
| Long-term memory | versioned temporal knowledge, Hindsight-like design | support patterns and memory corrections | contamination safety and retrieval uplift |
| Multimodal operations | OCR, vision, speech | synthetic invoice/document/receipt analysis | source-grounded extraction tests |
| Agents over documents | controlled PDF/XLSX parsers | contract terms and evidence references | robust parsing and provenance |
| Small/local models | quantized LLMs, on-device CPU/GPU | offline incident analysis lab | reproducible hardware and quality data |
| Distillation | model-to-model training | small verifier or intent router | holdout gain, license check |
| Synthetic data research | scenario grammar, model-based generation | hard case generation | novelty vs oracle correctness |
| Differential testing | multiple frameworks/tool executors | same case under two agent SDKs | tool/result equivalence |
| Federated protocol research | A2A, signed evidence exchanges | mock dispute handoff between institutions | identities, scoped permissions, timeouts |
| Formal verification | TLA+/PlusCal, property testing | policy invariants and event projection | no violations in modeled state space |
| Temporal workflow | Temporal/LangGraph persistence | pause/retry/resume after crash | exact-once effect in sandbox |
| Software architecture tutor | guided ADR and performance profiler | diagnose incident from trace | human comprehension outcomes |
| Accessibility research | screenreader-guided agent inspector | trace interpretation without vision | task completion in accessibility audit |
| AI incident forensics | cross-run correlation, regression clustering | explain repeated failure cohorts | true/false cluster audit |
| Human attention economics | queueing, reviewer allocation | policy for review routing | backlog versus error-rate trade-off |
| Data privacy engineering | selective redaction, local processing | BYOK privacy modes | egress/deletion verification |
| Privacy-preserving learning | differential privacy/federated simulation | synthetic multi-team data aggregation | realistic threat model + utility |
| Agent UX patterns | interactive simulations, adaptive explainers | tutor/observer/expert modes | measured comprehension, not cosmetic AI |
| Financial ops digital twin | event-sourced network simulations | virtual merchant/service pressure test | reproducibility and bounded validity |
| Competitive economics | game theory/market design | simulated service incentives | no unsupported real-economy claims |

**Watchlist cadence:** annual or release-driven review of vendor APIs, pricing, benchmarks, standards and model support. Upgrade only after testing. Do not silently label future research 'built'.
